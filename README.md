# Oracle-Aware Prompt Refinement for LLM-Generated JUnit Tests

**Exploratory Evaluation of Executable Test-Suite Recovery on ClassEval-T**

## Overview

This project investigates the reliability of unit tests generated by Large Language Models (LLMs), focusing on compilation failures, incorrect test oracles, incompatible test setups, and behavioral misunderstandings.

We evaluate an **Oracle-Aware Prompt Refinement (OAPR)** workflow that uses source-code inspection and failure analysis to guide the regeneration of failing JUnit test suites.

The project uses 94 Java class-level tasks from ClassEval-T and evaluates test generation using ChatGPT and Gemini.

## Research Methodology

The experiment consists of two stages.

**Stage 1 — Historical P0/P1 Recovery**

1. Generate JUnit tests using a baseline prompt (P0).
2. Compile and execute the generated tests.
3. Identify eligible failures.
4. Analyze failures against the Java source and execution reports.
5. Generate revised tests using OAPR (P1).
6. Evaluate whether the revised suites compile and pass.

**Stage 2 — Round 2 Evaluation**

Three prompting conditions are evaluated separately:

- **Baseline / P0 Resample:** Regeneration without the oracle-aware checklist.
- **Checklist Only:** Regeneration using a structured source-first checklist.
- **Checklist + Focus:** Checklist plus task-specific diagnostic guidance.

JUnit execution results and mutation testing outcomes are recorded for each condition.

|---|---|---:|---:|
| ChatGPT | P0 Resample | 23/33 | 88.90% |
| ChatGPT | Checklist Only | 33/33 | 79.38% |

## Evaluation Metrics

A generated test suite is considered **PASS** only when:

1. The suite compiles successfully.
2. At least one JUnit test executes.
3. No assertion failures or execution errors occur.

Mutation testing is performed on JUnit-valid suites. Baseline-failing suites are excluded rather than assigned a zero mutation score.

## Research Limitations

- The historical P0/P1 study uses a failure-selected cohort and manually informed refinement.
- Original model sessions and sampling parameters are not fully independently verified.
- The Round 2 protocol's prospective freeze is not established by the retained historical evidence.
- The CE023 case involves a source-snapshot discrepancy and requires sensitivity analysis.
- JUnit PASS measures compatibility with the evaluated implementation, not independent specification correctness.
- Mutation testing results do not independently establish causal benefits from prompt refinement.

Therefore, this research reports exploratory observations rather than confirmed causal effects.
